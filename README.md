# Dots

Минималистичное PWA-приложение для цели в часах.

- Одна цель
- 1 точка = 1 час
- Прогресс хранится на устройстве
- Работает офлайн после первого открытия

## GitHub Pages

Для публикации:

1. Создай пустой репозиторий на GitHub.
2. Запушь этот проект в ветку `main`.
3. В настройках репозитория открой `Pages`.
4. Выбери `Deploy from a branch`, ветка `main`, папка `/root`.
